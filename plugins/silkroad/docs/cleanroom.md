# 净室开发规则

SilkRoad 的目标是实现跨境电商智能体的**功能**，而不是复制任何现有产品。

## 不允许进入本仓库的内容

- 其他商业产品的源码、反编译代码、提示词、skill 正文、智能体模板文本，无论是否改名。
- 从这些内容机械改写、翻译或逐段改述得到的文本。
- 其他产品私有接口的工具清单、参数说明原文。
- 没有开源许可证的第三方 skill 或代码，例如 Kalodata 的 `sailtonight/kalodata-skill`（仓库未声明许可证）。只能参考它公开页面上的能力列表，不读、不抄它的 SKILL.md、playbooks 和 CLI 代码。

## 允许的参考来源

- 功能层面的需求：有哪些场景、要解决什么问题、输入和输出是什么（用我们自己的话写进 `docs/requirements/`）。
- 数据供应商的**公开**官方文档（FastMoss、SerpApi、AnySearch、Kalodata 开放中心 API 文档、TikTok Shop 开放平台等）。
- DeepSeek Harness 的开源代码与文档（MIT）。
- 跨境电商的公开行业知识。

## 流程

1. 需求表只写场景、行为、数据需求和人工确认点，不引用任何原文。
2. 写 skill 的人（或智能体）只读需求表和供应商公开文档。
3. 合并前做相似度检查：不得出现与第三方产品文本雷同的段落。
