# P4 达人与营销：功能需求

净室说明同 P2：只写场景、行为、数据和人工确认点。

## 可用的数据和工具

| 来源 | 工具 | 说明 |
|---|---|---|
| FastMoss 达人 | `creator_search`、`creator_rank_top_ecommerce`、`creator_rank_top_growth`、`creator_rank_top_potential` | 找达人：按关键词、类目、地区，以及带货榜、涨粉榜、潜力榜 |
| | `creator_profile_overview`、`creator_data_trends`、`creator_fans_distribution`、`creator_cargo_summary`、`creator_product_list`、`creator_video_analysis` | 评估达人：粉丝和互动、带货表现、粉丝画像、带货品类、视频风格 |
| FastMoss 商品 | `product_creator_analysis`、`product_video_list` | 竞品是哪些达人在带、哪些视频卖得好 |
| FastMoss 视频 | `video_detail_analysis`、`video_script_info` | 爆款视频的内容和话术 |
| 本地知识库 | `silkroad_knowledge` | 商品资料、卖点、禁止的宣称（写简报和邮件用） |
| 自己的店铺 | `silkroad_tts_products` | 商品详情、价格 |

**SilkRoad 不发送任何邮件或私信。** 建联邮件默认只出草稿，用户复制后自己发送。以后可以接 Gmail OAuth，但仍然是"用户确认后发送"。

## S13 达人发现 `tiktok-creator-discovery`

**场景**：卖家要给一个商品找合适的带货达人，希望拿到一份有依据的短名单，而不是只看粉丝数。

**输入**
- 必需：商品（自己的商品或描述）、目标站点。
- 可选：达人粉丝量级偏好、预算（佣金率、是否付坑位费）、内容形式（短视频/直播）、数量。

**行为**
1. 三路找候选：
   - 同类竞品的带货达人（`product_creator_analysis`，竞品可先用 `product_search` 找）。
   - 类目和关键词搜索（`creator_search`）。
   - 榜单（带货榜、涨粉榜、潜力榜）。
2. 去重后评估每个候选：
   - 带货能力：近期 GMV、带货视频/直播数、主带品类是否匹配（`creator_cargo_summary`、`creator_product_list`）。
   - 粉丝匹配：地区、性别、年龄是否匹配目标买家（`creator_fans_distribution`）。
   - 状态：粉丝和互动趋势是否健康，是否有异常涨粉（`creator_data_trends`）。
   - 内容风格：适不适合这个商品（`creator_video_analysis`）。
3. 分层：头部（背书和爆发）、腰部（主力）、尾部和素人（铺量和素材）。给出每层建议数量。
4. 打分排序，说明每个人入选的理由和风险。

**输出**
- 短名单表：达人、粉丝量、地区、主带品类、近期带货表现、粉丝匹配度、内容风格、推荐理由、风险、联系方式（若 FastMoss 返回公开的商务邮箱）。
- 分层建议和合作方式建议（纯佣金 / 寄样 / 付费）。

**人工确认**
- 最终联系谁由用户决定。
- 只使用公开的商务联系方式。

## S14 达人建联邮件草稿 `tiktok-creator-outreach`

**场景**：选好达人后，卖家要用达人的语言写第一封合作邀请，以及跟进邮件。

**输入**
- 必需：达人（名单或单个）、商品、合作条件（佣金率、是否寄样、是否付费、期望内容形式）。
- 可选：品牌介绍、发件人名字、语气。

**行为**
1. 针对每个达人个性化：提到他具体的一两条视频或带过的同类商品（来自 FastMoss 数据），说明为什么适合他。
2. 用达人所在市场的语言写；简短（首封 120 词以内）、主题行具体、合作条件清楚、行动号召明确（回复/申请样品/加入定向计划）。
3. 产出首封邮件和两封跟进（第 3 天、第 7 天），以及 TikTok 私信短版本。
4. 遵守规则：不夸大商品功效，不承诺无法兑现的收益，写明是商业合作；不使用非公开联系方式。

**输出**
- 每个达人：主题行、正文（目标语言）+ 中文对照、两封跟进、私信短版本。
- 批量时汇总成表，便于复制。

**人工确认**
- 只出草稿，用户自己发送。佣金和费用条件由用户确认。

## S15 寄样简报 `tiktok-sample-brief`

**场景**：达人同意合作、样品寄出时，卖家需要给达人一份清楚的内容简报，让视频既符合达人风格又能卖货、又不违规。

**输入**
- 必需：商品、达人（或达人类型）、目标站点。
- 可选：参考视频（自己或竞品的爆款）、必须出现的卖点、截止时间、发布要求（挂车、标签、广告授权码）。

**行为**
1. 从知识库和商品详情提炼 3 个以内核心卖点和必须避免的宣称。
2. 用 `product_video_list`、`video_script_info` 找同类爆款视频的结构，提炼可借鉴的钩子和展示方式（不抄原话）。
3. 结合达人风格写简报：
   - 商品介绍和核心卖点（达人语言）。
   - 推荐的内容结构（钩子、展示、证明、行动号召），2 到 3 个创意方向供达人选。
   - 必须做：出镜展示的点、挂购物车、话题标签、披露广告合作。
   - 不能做：禁止的宣称、竞品对比的红线、平台违规点。
   - 交付要求：时长、发布时间、是否需要 Spark Ads 授权码、素材二次使用授权。
   - 寄样信息：样品清单、到货后多少天内发布。

**输出**
- 一页简报（达人语言）+ 中文版，便于用户核对。

**人工确认**
- 简报内容和合作条款由用户确认后再发给达人。
