# TikTok Shop 寄样简报

> **TikTok 数据来源**：下文写的是 FastMoss 工具。`silkroad_status` 显示 FastMoss 没连上、Kalodata 为 `configured` 时，改用 Kalodata：按 `kalodata-data` 技能第 5 节的对照把每一步换成 `silkroad_kalodata_*` 工具，费用控制和口径照那个技能；Kalodata 没有对应的数据写"没有数据（Kalodata 不提供）"。两个都连上时默认用 FastMoss，用户指定时听用户的；两个都没有时才按本技能的降级方式处理。

达人同意合作、样品即将寄出时，给达人一份清楚的内容简报。目标是视频既符合达人风格、能讲清卖点，又不违规。

简报是草稿。用户确认后才发给达人，SilkRoad 不发送。

## 0. 确认输入

- **必需**：商品；达人（或达人类型）；目标站点。
- **可选**：参考视频（自己或竞品的爆款）；必须出现的卖点；截止时间；发布要求（挂购物车、话题标签、广告授权码）；素材二次使用授权范围。
- 寄样清单和到货后发布天数由用户填写。缺失时留空并标注"待填"。

## 1. 检查数据源

调用 `silkroad_status`。

- FastMoss 未连接：简报照写，"参考视频"一节写"没有数据"。告诉用户：请打开左侧栏「跨境电商」面板的「数据源」登录 FastMoss，之后可以补充爆款结构。
- 不索要任何密码或 API key。

## 2. 提炼卖点与禁区

- 调用 `silkroad_knowledge`（`query` 传商品名）读取卖点、规格和禁止宣称。
- 自家商品的标题、价格和 SKU 可用 `silkroad_tts_products`（传 `product_id`）读取。
- **核心卖点**：最多 3 个。每个卖点附一个"证据画面"要求，例如实物、演示、尺寸参照。
- **禁止宣称**：功效、绝对化用语、未经证实的对比、他人商标等。
- 未经用户确认的卖点标为"待确认"，不写进简报。

## 3. 参考爆款结构（可选，推荐）

- `mcp__fastmoss__product_video_list`：同类商品的带货视频，先取一页。
- `mcp__fastmoss__video_script_info`：挑 1–2 条表现好的视频，看口播结构。
- `mcp__fastmoss__video_detail_analysis`：看播放和互动数据。
- 只提炼钩子类型、结构骨架和展示方式。不抄原话，不照搬镜头序列。
- 控制额度：少量调用，完成后先给初步结论，再决定是否深挖。

## 4. 写简报

用达人的语言撰写（站点语言），中文版附后。按下面结构组织，一页之内写完。

1. **商品介绍**：一段话，讲清它是什么、适合谁用。
2. **核心卖点**：最多 3 条，每条配证据画面。
3. **创意方向**：2–3 个供达人选。每个方向包括钩子、展示、证明和行动号召。方向之间要有明显差异。
4. **必须做**：出镜展示的点；挂购物车（按平台当前界面表述）；话题标签；披露广告合作。
5. **不能做**：禁止宣称；竞品对比的红线；平台违规点；需要授权的音乐和商标。
6. **交付要求**：视频时长；发布时间；是否需要广告授权码（Spark Ads）；素材二次使用授权范围。
7. **寄样信息**：样品清单（必须是售卖版本）；到货后发布天数（待填）；联系人。

### 发出前的检查

| 检查项 | 是否完成 |
|---|---|
| 卖点都已经用户确认 | |
| 禁止宣称已写入"不能做" | |
| 样品是售卖版本，和上架信息一致 | |
| 交付时长、截止时间和发布天数已填 | |
| 广告授权码和素材授权范围已确认 | |
| 中文版已附，用户已核对 | |

## 5. 合规检查

- **广告披露**：要求达人按 TikTok 当前规则披露合作。规则以平台官方为准。
- **危险品与特殊品类**：电池、液体、刀具、儿童用品、食品、化妆品。写明安全画面，并提醒用户核对合规要求。
- **出镜授权**：达人本人书面同意。广告用途需要额外确认。
- **风险提示**：只做提示，不做法律结论。高风险项提醒用户找合规人员确认。

## 6. 输出模板

```
## 结论
给 <达人> 的简报草稿：推荐创意方向 A，理由……（附数据来源和时间范围；无数据则写"未核实数据"）

## 简报（达人语言）
（第 1–7 节，一页之内）

## 中文对照
（同上）

## 合规检查
（第 5 节；没有问题写"未发现明显风险项"）

## 待确认
- 卖点与宣称
- 寄样清单、发布天数、截止时间
- 广告授权码与素材授权

## 建议下一步
- 用户确认后，再发给达人
```

## 7. 寄样后的节奏

- 简报随样品一起发出，或在样品到货前发出。建议先发简报，让达人先确认方向。
- 到货后的发布天数以用户填写的为准。没有填写时，不替用户承诺时间。
- 逾期未发布时，建议用户先礼貌询问进度，而不是直接催促或扣款。扣款或违约条款由用户与达人自行约定，不在简报里写。
- 视频发布后，用 `mcp__fastmoss__video_detail_analysis` 或 `creator_video_analysis` 复盘，结果可用于下一轮选人。复盘时只用工具返回的数据。

## 8. 人工确认点

1. 卖点、宣称和合作条款，由用户确认后才能发给达人。
2. 寄样清单和发布天数由用户填写。
3. 简报由用户自己发送。

## 9. 异常处理

- 参考视频为空：只写原创的创意方向，注明"无参考数据"。
- 用户要求"照着某个视频拍一样的"：拒绝逐镜或逐句复制，改为提炼结构，并给出原创方向。
- 卖点与知识库矛盾：列出冲突，请用户决定，不擅自选择。
- 价格、活动或库存信息只用用户提供或工具返回的数据，不编造。
