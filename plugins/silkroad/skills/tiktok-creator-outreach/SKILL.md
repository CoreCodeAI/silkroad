# TikTok Shop 达人建联草稿

> **TikTok 数据来源**：下文写的是 FastMoss 工具。`silkroad_status` 显示 FastMoss 没连上、Kalodata 为 `configured` 时，改用 Kalodata：按 `kalodata-data` 技能第 5 节的对照把每一步换成 `silkroad_kalodata_*` 工具，费用控制和口径照那个技能；Kalodata 没有对应的数据写"没有数据（Kalodata 不提供）"。两个都连上时默认用 FastMoss，用户指定时听用户的；两个都没有时才按本技能的降级方式处理。

为选中的达人写合作邀请、跟进邮件和私信短版。

**只出草稿。SilkRoad 不发送任何邮件或私信，发送由用户自己完成。** 以后若接入邮箱授权（如 Gmail OAuth），发送前仍需用户逐条确认，不得自动发送。

## 0. 确认输入

- **必需**：达人（名单或单人）；商品；合作条件，包括佣金率、是否寄样、是否付费（金额由用户提供）、期望的内容形式。
- **可选**：品牌介绍；发件人名字和职位；语气（专业或轻松）。
- 合作条件缺失时要问用户。不替用户定佣金、费用或样品政策。

## 1. 检查数据源和资料

- 调用 `silkroad_status` 确认 FastMoss 状态。未连接时，请用户打开左侧栏「跨境电商」面板的「数据源」登录 FastMoss。
- 没有 FastMoss 数据时只能写通用邀请，并在草稿里标注"未个性化"。不能假装提到了达人的视频。
- 调用 `silkroad_knowledge`（`query` 传商品名）读取卖点和禁止宣称。卖点不清楚时，用 `silkroad_tts_products`（传 `product_id`）读取自家商品详情。

## 2. 个性化（每个达人）

取一到两条依据，写进邮件的第一段：

- `mcp__fastmoss__creator_video_analysis` 或 `mcp__fastmoss__creator_product_list`：他的视频风格，或带过的同类商品。
- 说明为什么适合他：内容风格、受众地区、过往带货品类。
- 不编造他的视频、数据或受众特征。找不到依据，就只写通用理由，并标注。

## 3. 写作规则

- **语言**：达人所在市场的语言。每封草稿附中文对照。
- **长度**：首封不超过 120 词。
- **主题行**：具体，包含商品或合作类型。不用夸张的感叹号或"URGENT"之类的词。
- **结构**：一句自我介绍 → 为什么是他 → 合作条件（佣金、寄样、费用）→ 一个明确行动（回复、申请样品、加入定向计划）。
- **披露**：写明是商业合作。
- **不夸大**：不夸大商品功效，不承诺收益或销量，不写"保证爆单"之类的话。
- **联系方式**：只用公开的商务渠道。不提"从别处获得的邮箱"。
- **隐私**：不索取达人的账号密码或私人信息。

## 4. 产出

每个达人一组：

1. **首封**：主题行、正文（目标语言）、中文对照。
2. **跟进一**：第 3 天，简短提醒，附一条新信息（如样品或活动时间）。
3. **跟进二**：第 7 天，礼貌收尾，留一个回复的口子。
4. **TikTok 私信短版**：不超过 60 词，目标语言。

批量时汇总成表：达人、主题行、状态（草稿）、发送日期（由用户填写）、跟进日期。

### 跟进节奏

- 最多两次跟进。达人没有回复，就停止，不再追加。
- 达人明确拒绝或说"不合作"，立即标记为"不再联系"，草稿里也不再生成跟进。
- 同一个达人的不同合作条件，只能给一个版本的草稿，避免前后矛盾。

### 分批建议

- 先发头部和腰部的首批（建议 5–10 封），看回复率后再扩大。
- 回复率低时，优先检查个性化依据是否具体、合作条件是否清楚，而不是加大发送量。
- 回复率数字只有用户自己发送后才有，草稿阶段不要预估。

## 5. 交给用户前的检查

| 检查项 | 是否通过 |
|---|---|
| 写明了商业合作 | |
| 佣金和费用与用户确认的一致 | |
| 个性化依据来自工具结果 | |
| 没有夸大功效或收益承诺 | |
| 联系渠道是公开的商务渠道 | |
| 首封不超过 120 词 | |

## 7. 人工确认点

1. 每封草稿都由用户审阅后自行发送。SilkRoad 不发送。
2. 佣金、寄样和费用条件由用户确认。
3. 联系哪些达人由用户决定。

## 8. 异常处理

- 达人没有公开商务联系方式：草稿照写，标注"联系方式待用户自行确认"。不猜邮箱。
- 目标语言不确定：问用户，不要默认。
- 用户要求"写得更夸张"或"保证合作"：拒绝夸大，改成具体、可核实的表述，并说明原因。
- FastMoss 返回为空：写通用版本，注明未个性化，不编造达人的内容。
